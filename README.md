# FinPay DevOps Lab

A hands-on DevOps training project simulating a fictional fintech platform, FinPay.

## Goal
Build practical, interview-ready DevOps experience covering:
Linux, Git, Docker, Kubernetes, Helm, CI/CD, AWS/EKS, Monitoring, and Security.

## Components (to be built progressively)
- REST API
- Background worker
- PostgreSQL database
